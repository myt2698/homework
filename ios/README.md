# 作业小计划 · iOS 原生源码

Swift + SwiftUI 工程，部署目标 iOS / iPadOS 16.0 及以上，兼容 iPad 横竖屏和分屏、iPhone。无第三方原生依赖，不登录，不上传作业或录音。

**当前交付是源码，不是安装包。此 Windows 环境未进行 Swift 编译、Xcode 构建、模拟器或真机验证。语法解析不能验证 Apple API 类型、运行行为或签名配置。**

## 工程入口

- `HomeworkLedger.xcodeproj`：已生成并纳入版本管理的 Xcode 工程，打开即可查看源码，不需要先安装工程生成工具。
- `HomeworkLedger/HomeworkLedgerApp.swift`：SwiftUI 应用入口。
- `HomeworkLedger/Core`：Foundation 数据模型、计划规则、计时、结算、旧版迁移与备份处理。
- `HomeworkLedger/LedgerStore.swift`：原子本地保存、恢复快照、计时与页面状态协调。
- `HomeworkLedger/Views`：首页、计划、排序、专注、休息、听写、成长足迹、设置及备份页面。
- `HomeworkLedger/Services`：系统录音/播放、通知、PDF 与离线查字桥接。
- `Tests/LedgerCoreTests.swift`：业务规则 XCTest，当前环境仅解析了测试源码，**没有执行**。

## 已实现的源码路径

- 每个真实日期一张清单；1–366 天计划范围、关键词与序号分项录入、预计用时、按所选日期重复添加、改期、删除与 15 秒撤销。缩短范围不删除其他日期任务。
- 依次点选排序，保留草稿与原卡片位置；开始后的排序只调整未开始作业，已开始/暂停/完成项保持位置。
- 开始时间选择、5/10 分钟快捷填入、专注计时、休息 5/10/15 分钟或指定返回时间、一次延长 3 分钟、跳过并开始下一项。关闭再打开按保存的绝对时间恢复。
- 任务完成后安排下一项；最后一项完成自动按 20:30 / 20:40 / 21:30 阈值结算，打卡独立。8 秒快捷撤销完成，补加作业清除原完成结算。
- 四项习惯打卡、运动项目、成长足迹、本周预计/实际用时、旧周末结算归档、家长修改结算时间与删除日记录。
- 25 组、318 个内置听写词语；自定义词语；逐词录制/重录/试听/删除。录音成功后自动试听，每词播放两遍，间隔沿用网页版。没有用合成语音替代听写录音。
- 导入/导出 v3 JSON 备份，兼容现有 web / Android 字段，保留未知字段；导入前快照与恢复；导入计时一律暂停，移除当前提醒。存储失败不提交内存变化，原文件不可读时停止普通写入，并保留文件供恢复。
- 原生 A4 PDF 排版、中文自动换行、长内容分页、日期范围选择、系统文件导出与打印/分享。
- 本地 WKWebView 仅用于查字，直接引用仓库 `../web/hanzi`，含 9,574 字及原许可；主界面与业务不是网页套壳。查字期间计时继续。

## 平台差异与当前边界

- iOS 使用原生导航、表单、日期选择器、文件选择和分享菜单；布局与现有网页/安卓不完全相同。重复任务可选择同时修改未来未开始的同系列任务。
- 计划页顶部“确定”确认当前选中日期，其他日期分别确认；从计划页进入排序后，在排序页点“确定”同时保存并确认当天计划。首页/专注页的未开始顺序调整只改变顺序。
- iOS 应用内提醒播放两遍，未录自定义提示音时读出“作业时间到啦”。锁屏提醒使用系统通知：未自定义时是系统声音，自定义时使用本机 CAF 录音。声音受系统通知授权、静音和专注模式控制，iPad 不提供安卓式震动承诺。
- 每次为当前提醒安排至多 48 次系统通知：首次到点和之后每 5 分钟一次，覆盖首次提醒后的 3 小时 55 分钟。重新进入前台会补充队列。前台每 5 分钟继续提醒；应用长时间未打开时，不能无限期补充后台通知。
- 录音限 0.4–10 秒。进入后台、音频中断或离开录音/听写页会停止操作；未保存的新录音会丢弃，原录音保留。听写不在锁屏后台继续播放。
- 记录与录音分别存于应用私有目录。JSON 备份不包含任何录音，设备之间不自动同步。通知许可是系统设置，不写入通用备份。
- 未支持多窗口，防止同一数据文件被两个窗口同时写入。当前按现有应用提供浅色外观。

## 在当前电脑上检查源码

在仓库根目录运行以下命令，只解析源码和配置，不调用编译器：

```powershell
python scripts/prepare-ios.py
node web/tests/check-bindings.test.cjs
python scripts/check-ios.py --parser-path <临时语法解析器目录>
```

解析器目录需要 `tree-sitter==0.26.0`、`tree-sitter-swift==0.7.4`、`tree-sitter-java==0.23.5` 三个 Python wheel。可用 `python -m pip install --only-binary=:all: --target <临时目录> ...` 单独放在临时目录，**不需要 Swift、Xcode、Android SDK**。检查脚本会解析全部 Swift/Java、工程引用、scheme、plist、资源路径和词表一致性。网页脚本与元素绑定由现有检查覆盖。

修改内置词表或新增/删除 Swift 文件后，重新运行 `prepare-ios.py`。它只更新词表 JSON 和工程引用，不构建、不下载依赖。AppIcon 沿用仓库安卓原生勾选图标的矢量几何与配色，iOS 使用不透明 1024 像素资源。

1. 复制**整个仓库**，保留 `ios` 与 `web/hanzi` 的相对位置，打开 `ios/HomeworkLedger.xcodeproj`。
2. 在 Signing & Capabilities 选择自己的开发团队，必要时修改 `com.homework.ledger.ios` 包标识。

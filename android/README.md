# Android 原生版

这是“作业小账本”的 Android 原生 Java 工程。

- 应用包名：`com.homework.ledger`
- 最低版本：Android 6.0 / API 23
- 编译版本：API 35
- Java 版本：17
- 数据存储：`SharedPreferences` + JSON
- 网络权限：无
- 麦克风权限：仅在用户点击作业离线语音录入或词语人工录音时请求
- 第三方运行依赖：sherpa-onnx 1.13.7（随 APK 打包）
- APK 架构：`arm64-v8a`、`armeabi-v7a`

顶部“听写”入口会进入独立的四上语文听写页。词语表按 21 个课程或语文园地整理，共 220 个内置词语；每一组都可以继续添加自定义词语。每个词都提供人工录音、重录、试听和删除录音功能，自定义词还可以从词语表中删除。本课全部词语录齐后才能开始听写；练习时词语表自动隐藏，每条家长人声连续播放两遍，两遍之间停顿 1 秒；四字词与下一个词之间停顿 3 秒，其他词语停顿 2 秒，并显示当前进度。人工录音只保存在应用私有目录，不会上传网络，卸载应用时一并删除。

应用按“核对钉钉和成长记录册—录入并确认作业清单—逐项专注”的顺序记录。当天页面只显示日期、成长能量、作业核对、作业清单与结算；每日录入工具收进弹窗，首页仅保留一个“录入作业”入口，运动、阅读、家务及装饰性提示不再显示。弹窗使用 APK 内置的 sherpa-onnx 中文模型直接从麦克风进行流式离线识别，识别过程不会上传录音，也不依赖手机系统语音服务；点击一次开始录音，再次点击停止并将文字填入输入框，单次最长 2 分钟。录音中点击“生成作业清单”会先自动停止录音，等待最终识别文字后再生成；点击“清空”会停止录音并丢弃本次识别结果，避免文字再次填回；点击弹窗外的灰色遮罩不会误关弹窗。也可以直接输入文字；生成一科后可以继续录下一科，并在同一弹窗下方核对、使用醒目的“删除作业”按钮移除错误项目，再确认清单。文字清单优先按 `1.`、`2.`、`3.` 等序号分项，正文句号不会拆分任务。录入时可单选语文、数学、英语或科学标签快速归类；弹窗内的待确认清单固定按语文、数学、英语、科学排列，同一科目内保持录入先后顺序，确认后首页才显示闯关清单并让孩子自由安排顺序。

清单确认后，孩子可以长按拖动卡片或使用上下箭头安排自己的闯关顺序；确定后才进入“闯关模式”，第一项开始后顺序自动锁定。闯关页面突出当前一项，只预告后两项，其余作业和已完成作业默认折叠；顶部显示完成比例、剩余项数和阶段性鼓励。同一时间只能进行一项作业，开始或继续时会弹出专注计时卡，显示首次开始时间和实时用时。完成一项后自动切换到下一关，全部完成时显示通关庆祝，并保存整体完成时刻、自动结算。

历史记录通过顶部成长能量卡中的“成长足迹”入口进入独立页面，首页不再直接展示历史列表；系统返回键或页面返回按钮都可以回到当天任务。

周五至周日自动共用一份作业清单。周五录完并确认后，从页面上唯一的“周五安排与闯关”入口打开弹窗，先给每项作业选择周五、周六或周日；关闭弹窗后分别排列三天的闯关顺序。周五可以立即开始当天任务，周六、周日继续按同一份计划执行，不需要重新录入。前一天未完成的项目会优先顺延到第二天。周末奖励分为“周五制定计划”和“按计划日期完成”两部分，最高仍为 ¥1.50。

用 Android Studio 打开当前 `android` 文件夹即可编辑和运行。首次同步时，Android Studio 会提示安装缺少的 SDK 或 Gradle 组件。

核心界面和记录逻辑位于：

`app/src/main/java/com/homework/ledger/MainActivity.java`

APK 不再包含预生成的听写音频或文字转语音模型。作业语音录入所需的 sherpa-onnx Android 运行库与量化中文识别模型仍会随 APK 一起安装，确保识别完全离线；详细许可见仓库根目录的 `THIRD_PARTY_NOTICES.md`。

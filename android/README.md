# Android 原生版

这是“作业小计划”的 Android 原生 Java 工程。

- 应用包名：`com.homework.ledger`
- 最低版本：Android 6.0 / API 23
- 编译版本：API 35
- Java 版本：17
- 数据存储：`SharedPreferences` + JSON
- 网络权限：无
- 麦克风权限：仅在用户点击词语人工录音或自定义休息提示音时请求
- 震动权限：仅在休息倒计时结束时使用，无需运行时授权
- 作业录入：键盘与关键词，不再加载语音识别运行库
- 预计用时：新增默认 15 分钟，在录入清单的日期旁或调整顺序列表修改
- 查字：首页和专注计时页均有入口，内置 9,574 字的笔顺动画与跟写；在本地 WebView 中复用网页版组件，离线加载，不增加网络权限。关闭后返回原页，专注计时持续运行。
- 专注计时：移除关闭入口，返回键和点击弹窗外侧均不关闭；保留“完成这项”“休息一下”，新增“跳过，开始下一项”。跳过会保留累计用时并暂停当前项，按原计划直接开始当天另一项未完成作业；不产生休息记录、不算完成，没有其他可做项时禁用跳过。重新打开应用后恢复当天正在进行的专注卡。

顶部“听写”入口会进入独立的四上语文听写页。词语表按 25 个课程或语文园地整理，共 318 个内置词语；页面会记住上次选择的课程，并支持通过“上一课 / 下一课”快速切换。每一组都可以继续添加自定义词语。每个词都提供人工录音、重录、试听和删除录音功能，孩子或家长都可以录制；停止并成功保存后会自动试听刚才的录音。自定义词还可以从词语表中删除。本课全部词语录齐后才能开始听写；练习时词语表自动隐藏，每条录音连续播放两遍，两遍之间停顿 1 秒；四字词与下一个词之间停顿 3 秒，其他词语停顿 2 秒，并显示当前进度。人工录音只保存在应用私有目录，不会上传网络，卸载应用时一并删除。

应用按“核对钉钉并补全成长记录册—录入与安排—逐项专注”的顺序使用。录入、完成日期和可选排序在同一个全屏下级页面中完成，首页只保留录入或修改计划入口；奖励和统计仍在足迹页，四项习惯打卡在作业清单上方以两列常驻展示，仅运动项目按需展开。底部固定科目、关键词、输入框和加号，新增作业默认预计 15 分钟，可在清单日期旁或调整顺序列表修改估时。新作业接在末尾，清单不再按科目自动重排，用科目颜色区分；补录保留已有顺序，删除撤销后回到原位置。文字仍支持按 1.、2.、3. 分项，不按正文句号拆分。

默认按录入顺序执行，可以直接点击右上角的“确定”。需要调整时，在同一录入页面点击“调整顺序”，暂时隐藏输入区，按先后点选作业，支持撤销、重选和关闭后恢复草稿；选完后共用同一个确认按钮。确认时一次保存作业、完成日期和顺序，再安排第一项的开始时间：默认当前时间，确认即可开始；“5分钟后”“10分钟后”按点击时的时间计算并填入，仍需确认，也可自行选择具体时间。预计用时仍支持 5、10、15、20、30、35、40、45、50、60 分钟。第一项开始后整份计划锁定，执行、计时和作业结算保持不变；庆祝状态仅在当天作业与四项习惯打卡都完成后出现。

每项作业完成后，只要当天还有可做的任务，就按孩子已排好的顺序弹出“我准备什么时候开始下一项？”；同样默认当前时间，支持 5/10 分钟后快捷填入或自选时间，再确认执行。恢复暂停作业也使用相同时间选择，重新选时间或重启应用后仍显示这项作业。当天全部完成后不再弹窗，也不会提示提前开始安排在周末其他日期的作业。作业进行中点击“休息一下”，仍可选择休息 5、10 或 15 分钟，或指定吃饭后的返回时间；休息倒计时只允许延长一次 3 分钟，并保存计划与实际返回时间。两种倒计时都可在应用重新打开后恢复，到点连续播放两遍提示音并震动，如果仍未开始，之后每隔 5 分钟再提醒一次。

历史记录通过顶部“足迹”入口进入独立页面，首页不再展示成长能量和历史列表；足迹页增加本周按计划完成天数、已完成作业的预计用时与实际用时对比。删除按钮只在“管理记录”模式出现。系统返回键或页面返回按钮都可以回到当天任务。

顶部“设置”进入独立二级页，可查看其他日期。“休息结束提醒”和“数据备份”各只保留一个入口，详细操作放在独立下级页面，返回时回到设置页。提示音支持录制、试听、重录和恢复默认，离开录音页会停止录音与试听；未录音时由系统中文语音提示“作业时间到啦”。备份格式与网页版一致，可手动迁移作业、计划、打卡和自定义词语；听写录音和休息提示音录音保存在应用私有目录，不包含在 JSON 备份中。

平时和假期的作业录入底部共用相同的控件尺寸与排列：科目、输入框、预计用时、加号，窄屏将预计用时与加号换到下一行；科目均使用原生单列单选列表。首页当前作业的内容、修改图标与预计用时垂直居中，开始按钮仍占满卡片高度。专注页使用暖橙色计时数字、科目色作业内容、中性灰辅助信息和绿色完成按钮，与网页版保持相同视觉重点。

周五至周日共用同一份任务。周五在录入清单的每项旁选择完成日，默认周六；顶部可查看全部、周五、周六、周日，并按天调整顺序，最终只确认一次。周六和周日继续执行同一计划，不重新录入；三天计划入口展示同一张只读清单。前一天未完成项优先顺延，周末奖励计算规则不变。

设置页新增“假期设置”入口，设置名称、起止日期和安排日期（默认前一天）。假期计划采用原生全屏页面：点选“今天、第一天、第二天……”切换当天清单，长假可左右滑动，无需打开日历；天数从假期首日计算，小字保留日期，“今天”同时标注对应天数。按天录入一次性任务，或选择“每天都做”一次生成各天独立任务，并可排除指定日期；沿用各科关键词和预计用时，按点选顺序安排当天任务。首页仅显示当天清单，假期前一天也可安排任务；漏做项可从“之前未完成”主动改期，保留已用时间。首次从首页确认计划后，若当天有任务，继续使用原来的第一项开始时间安排。

假期覆盖对应日期的周末入口，与已有周末计划冲突时不覆盖旧数据。已开始/完成的内容与计时受保护，重复任务批量修改只作用于选定日期起且不早于今天的未开始项。已有作业的假期不直接变更整段日期或删除，可改名、调整具体任务日期。假期任务完成只记录时间，不自动套用平日或周末奖罚；原有金额记录保留。假期配置、重复组标识及每日实例随 JSON 备份导出，与网页版互通。

日期框以较小字体显示天数，后面显示当天任务总数（包含已完成任务），添加、删除或改期后同步更新。假期作业卡片使用铅笔、垃圾桶图标修改和删除当天任务，改期采用“第几天”下拉选择框，选中目标天数后自动改期并保存；打开清单或选择原日期不会触发改期，失败时恢复原选择。可选择当前查看日期起、假期结束前的天数；首页漏做项仍能安排到假期后补做。

闯关顺序确定后，可以点击尚未开始的作业卡片，统一修改作业内容和预计用时，保存后保持原来的闯关顺序。

用 Android Studio 打开当前 `android` 文件夹即可编辑和运行。首次同步时，Android Studio 会提示安装缺少的 SDK 或 Gradle 组件。

核心界面和记录逻辑位于：

`app/src/main/java/com/homework/ledger/MainActivity.java`

假期的数据规则与原生页面分别位于同目录下的 `HolidayPlans.java` 和 `HolidayScreen.java`。

听写继续使用逐词人工录音，休息提示音录音功能也保留。已移除作业语音识别源码和运行依赖；历史识别模型文件暂留在仓库，但构建配置会排除它们，不再打包。`main.assets` 只包含 `../../web/hanzi`，不会打包其他网页或历史模型。查字资源原始约 31 MB，常规 ZIP 压缩约 12.6 MB，预期 APK 增量约 13 MB，未执行安卓构建。第三方许可见仓库根目录的 `THIRD_PARTY_NOTICES.md`。

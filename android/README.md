# Android 原生版

这是“作业小账本”的 Android 原生 Java 工程。

- 应用包名：`com.homework.ledger`
- 最低版本：Android 6.0 / API 23
- 编译版本：API 35
- Java 版本：17
- 数据存储：`SharedPreferences` + JSON
- 网络权限：无
- 第三方运行依赖：无

应用按“运动打卡—录入并确认作业清单—逐项专注—自动结算”的流程记录。运动打卡可多选跳绳、仰卧起坐、50米跑、踢毽子和坐位体前屈；作业可以调用手机自带的语音识别服务连续录入，也可以直接输入文字。录入时可单选语文、数学、英语或科学标签快速归类。同一时间只能进行一项作业；开始或继续时会弹出专注计时卡，显示首次开始时间和实时用时。最后一项完成后保存整体完成时刻，成长记录册确认后自动结算。

周五至周日自动进入周末模式，共用一份周末任务包。可以填写周五、周六上午、周六下午的计划分钟数和周六目标完成时间；周末奖励分为“完成周五安排”与“周六完成学校作业”两部分，最高仍为 ¥1.50。每日任务和必须周日完成的特殊任务可以单独标记，不纳入周六一次性作业目标。

用 Android Studio 打开当前 `android` 文件夹即可编辑和运行。首次同步时，Android Studio 会提示安装缺少的 SDK 或 Gradle 组件。

核心界面和记录逻辑位于：

`app/src/main/java/com/homework/ledger/MainActivity.java`

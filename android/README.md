# Android 原生版

这是“作业小账本”的 Android 原生 Java 工程。

- 应用包名：`com.homework.ledger`
- 最低版本：Android 6.0 / API 23
- 编译版本：API 35
- Java 版本：17
- 数据存储：`SharedPreferences` + JSON
- 网络权限：无
- 第三方运行依赖：无

应用按“核对钉钉和成长记录册—录入并确认作业清单—逐项专注—每日打卡”的顺序记录。运动打卡可多选跳绳、仰卧起坐、50米跑、踢毽子和坐位体前屈，另外可记录每日阅读和家务；作业可以调用手机自带的语音识别服务连续录入，也可以直接输入文字。文字清单优先按 `1.`、`2.`、`3.` 等序号分项，正文句号不会拆分任务。录入时可单选语文、数学、英语或科学标签快速归类。同一时间只能进行一项作业；开始或继续时会弹出专注计时卡，显示首次开始时间和实时用时。最后一项完成后保存整体完成时刻并自动结算。

周五至周日自动共用一份作业清单。周五录完并确认后，给每项作业选择周六或周日；周六、周日直接按这份计划执行，不需要重新录入。周末奖励分为“周五制定计划”和“按计划日期完成”两部分，最高仍为 ¥1.50。

用 Android Studio 打开当前 `android` 文件夹即可编辑和运行。首次同步时，Android Studio 会提示安装缺少的 SDK 或 Gradle 组件。

核心界面和记录逻辑位于：

`app/src/main/java/com/homework/ledger/MainActivity.java`

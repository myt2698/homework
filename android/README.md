# Android 原生版

这是“作业小账本”的 Android 原生 Java 工程。

- 应用包名：`com.homework.ledger`
- 最低版本：Android 6.0 / API 23
- 编译版本：API 35
- Java 版本：17
- 数据存储：`SharedPreferences` + JSON
- 网络权限：无
- 麦克风权限：仅在用户点击作业离线语音录入、词语人工录音或自定义休息提示音时请求
- 震动权限：仅在休息倒计时结束时使用，无需运行时授权
- 第三方运行依赖：sherpa-onnx 1.13.7（随 APK 打包）
- APK 架构：`arm64-v8a`、`armeabi-v7a`

顶部“听写”入口会进入独立的四上语文听写页。词语表按 25 个课程或语文园地整理，共 318 个内置词语；页面会记住上次选择的课程，并支持通过“上一课 / 下一课”快速切换。每一组都可以继续添加自定义词语。每个词都提供人工录音、重录、试听和删除录音功能，孩子或家长都可以录制；停止并成功保存后会自动试听刚才的录音。自定义词还可以从词语表中删除。本课全部词语录齐后才能开始听写；练习时词语表自动隐藏，每条录音连续播放两遍，两遍之间停顿 1 秒；四字词与下一个词之间停顿 3 秒，其他词语停顿 2 秒，并显示当前进度。人工录音只保存在应用私有目录，不会上传网络，卸载应用时一并删除。

应用按“核对钉钉和成长记录册—录入并确认作业清单—孩子制定顺序和时间计划—逐项专注”的顺序记录。当天首页不显示成长能量，优先保留日期、作业核对、作业清单、每日任务与结算；奖励和统计移到独立的“足迹”页面。未核对且没有清单时隐藏作业区；运动、中文阅读、数学思维和英文阅读默认收进“今日习惯”入口，并显示 `已完成数量 / 4`，需要时再展开打卡。运动可分别选择跳绳、踢毽子、坐位体前屈、50米和仰卧起坐。每日录入工具收进弹窗，首页保留一个“录入作业”入口。弹窗使用 APK 内置的 sherpa-onnx 中文模型直接从麦克风进行流式离线识别，识别过程不会上传录音，也不依赖手机系统语音服务；点击一次开始录音，再次点击停止并将文字填入输入框，单次最长 2 分钟。录音中点击“生成作业清单”会先自动停止录音，等待最终识别文字后再生成；点击“清空”会停止录音并丢弃本次识别结果，避免文字再次填回；点击弹窗外的灰色遮罩不会误关弹窗。也可以直接输入文字；生成一科后可以继续录下一科，并在同一弹窗下方核对、使用醒目的“删除作业”按钮移除错误项目，再确认清单。文字清单优先按 `1.`、`2.`、`3.` 等序号分项，正文句号不会拆分任务。录入时可单选语文、数学、英语或科学标签快速归类；弹窗内的待确认清单固定按语文、数学、英语、科学排列，同一科目内保持录入先后顺序，确认后首页才显示闯关清单并让孩子自由安排顺序。

清单确认后，孩子可以长按拖动卡片或使用上下箭头安排自己的闯关顺序，给每项选择 5、10、15、20 或 30 分钟的预计用时，并设置最多两个休息点。平日可以在任意项目后设置“饭前到这里”的吃饭分界；耗时较长的作业可以拆成多个小步骤。确定后才进入闯关模式，第一项开始后顺序自动锁定。闯关页面突出当前一项，只预告后两项，其余作业和已完成作业默认折叠；顶部紧凑显示完成比例、饭前或饭后阶段和动态预计剩余时间。同一时间只能进行一项作业，开始或继续时会弹出专注计时卡，显示首次开始时间、当前步骤和实时用时。完成一步后继续下一步，最后一步完成后自动切换到下一项；全部完成时显示通关庆祝，并保存整体完成时刻、自动结算。

普通作业完成后会直接突出清单中的下一项，不主动询问休息；只有完成预先设置的休息点，才自动打开休息安排。孩子可以直接选择休息 5、10 或 15 分钟，也可指定吃饭后的返回时间。“暂停”入口已改为“休息一下”，临时离开也使用同一套安排。倒计时可在应用重新打开后恢复，默认只允许延长一次 3 分钟；应用会保存计划与实际返回时间，时间到后连续播放两遍提示音并震动，如果下一项仍未开始，之后每隔 5 分钟再提醒一次，同时保留明确的“开始下一项”按钮。

历史记录通过顶部“足迹”入口进入独立页面，首页不再展示成长能量和历史列表；足迹页增加本周按计划完成天数、已完成作业的预计用时与实际用时对比。删除按钮只在“管理记录”模式出现。系统返回键或页面返回按钮都可以回到当天任务。

顶部“设置”进入独立二级页，可查看其他日期、导出或恢复本地 JSON 备份，并录制孩子自己的休息结束提示音。提示音支持试听、重录和恢复默认，未录音时由系统中文语音提示“作业时间到啦”。备份格式与网页版一致，可手动迁移作业、计划、打卡和自定义词语；听写录音和休息提示音录音保存在应用私有目录，不包含在 JSON 备份中。

周五至周日自动共用一份作业清单。周五录完并确认后，从页面上唯一的“周五安排与闯关”入口打开弹窗，先给每项作业选择周五、周六或周日；关闭弹窗后分别排列三天的闯关顺序。周五可以立即开始当天任务，周六、周日继续按同一份计划执行，不需要重新录入。前一天未完成的项目会优先顺延到第二天。周末奖励分为“周五制定计划”和“按计划日期完成”两部分，最高仍为 ¥1.50。

闯关顺序确定后，可以点击尚未开始的作业卡片，统一修改作业内容、预计用时和作业步骤，保存后保持原来的闯关顺序。

用 Android Studio 打开当前 `android` 文件夹即可编辑和运行。首次同步时，Android Studio 会提示安装缺少的 SDK 或 Gradle 组件。

核心界面和记录逻辑位于：

`app/src/main/java/com/homework/ledger/MainActivity.java`

APK 不包含 Kokoro、预生成的听写音频或其他文字转语音模型。听写仍必须使用逐词人工录制的语音。作业语音录入所需的 sherpa-onnx Android 运行库与量化中文识别模型仍会随 APK 一起安装，确保识别完全离线；详细许可见仓库根目录的 `THIRD_PARTY_NOTICES.md`。

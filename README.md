# 作业小账本

一个完全本地使用的家庭作业奖罚记录工具，包含离线网页版和原生 Android 版源代码。

## 奖罚规则

| 完成时间 | 金额 |
| --- | ---: |
| 8:30 及以前 | +¥1.50 |
| 8:30 后至 8:40 | +¥1.00 |
| 8:40 后至 9:30 | ¥0.00 |
| 9:30 以后 | −¥0.50 |

两个版本均支持：

- 设置统计开始日期；
- 通过语音转文字或键盘录入作业，可用语文、数学、英语、科学单选标签快速归类，也可从话语中自动识别科目；
- 确认作业清单后，每次只开始一项，分别记录暂停、完成和实际用时；
- 单项开始或继续时弹出专注计时卡，显示首次开始时间和实时用时；
- 分别记录跳绳、仰卧起坐、50米跑、踢毽子和坐位体前屈等运动打卡；
- 分别记录每项作业的开始、暂停、继续、完成和实际用时；
- 根据最终完成时刻自动计算奖罚；
- 按日期查看、补记或修改流程；
- 添加简短备注；
- 查看累计金额、记录天数、奖励天数和累计扣款；
- 删除历史记录；
- 在本机保存数据，不登录、不联网。

## 每天怎么用

1. 完成运动后，在“运动打卡”中选择当天实际完成的项目，可以同时选择多项。
2. 17:30 左右集中核对一次全部作业，点击“开始报作业”，按“科目＋内容”连续说完。
3. 核对自动生成的清单，确认没有遗漏后点击“确认作业清单”。
4. 孩子选择一项点击“开始”；弹出的专注卡会显示开始时间和实时用时，同一时间只能有一项正在进行。
5. 每项写完点击“完成”，临时离开或吃饭则在当前作业上点击“暂停”。
6. 回来后直接在对应作业上点击“继续”。
7. 最后一项作业完成后自动记录整体完成时刻；成长记录册确认后自动结算，无需再点“全部完成”。

如果最后一项作业完成时还没有确认成长记录册，App 会先保存真实完成时刻；稍后确认成长记录册时仍按这个时刻结算，不会把核对时间算成写完时间。

## 周末任务包

周五、周六和周日会自动显示同一份“周末任务包”，不再按平日规则要求周五完成全部作业，也不会和平日奖励重复计算。

周五先核对钉钉和成长记录册，并区分：

- 一次性学校作业：安排在周五、周六上午和周六下午完成；
- 每日任务：例如每天阅读、跳绳，不计入“周六全部完成”；
- 特殊任务：必须周日观察或完成的内容，单独安排。

周五至周日共用同一份作业清单，切换日期不会丢失任务进度。App 根据清单安排三个时段的计划分钟数，默认周六目标完成时间为 18:00，可以自行修改。
执行时可以分别确认“周五安排完成”和“周六上午安排完成”，让孩子看到自己是否真正按计划推进；上午里程碑用于培养计划执行习惯，不另外增加金钱奖励。

周末奖罚分为两部分：

- 完成自己安排的周五部分：+¥0.50；
- 周六目标时间前完成全部一次性学校作业：+¥1.00；
- 周六目标时间后、当天之内完成：第二部分为 +¥0.50；
- 周日才完成：第二部分为 ¥0.00；
- 周日结束仍未完成：第二部分为 −¥0.50。

因此周末最高奖励仍为 ¥1.50。周末累计有效作业时间来自每项作业自己的开始、暂停和完成记录。

## 使用网页版

直接双击 `web/index.html`，用浏览器打开即可。网页没有服务器依赖，也不需要安装任何软件。

记录保存在打开网页的这个浏览器中。清理浏览器的网站数据、更换浏览器或换电脑后，原记录不会自动迁移。

## 使用 Android 源代码

1. 安装 Android Studio。
2. 选择“打开项目”，打开本项目中的 `android` 文件夹。
3. 等待 Android Studio 下载所需的 Gradle 和 Android SDK 组件。
4. 连接安卓手机或启动模拟器，然后点击运行。

Android 版使用 Java 和 Android 系统原生控件编写，最低支持 Android 6.0（API 23），没有第三方运行依赖。语音录入调用手机自带的语音识别服务；如果手机没有可用服务，仍可直接输入文字。数据保存在应用自身的本地存储中；卸载应用会同时删除记录。

> 网页版和 Android 版各自在本机保存数据，目前不会自动同步。

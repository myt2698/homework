# 作业小计划

一个完全本地使用的家庭作业奖罚记录工具，包含离线网页版和原生 Android 版源代码。

## 奖罚规则

| 完成时间 | 金额 |
| --- | ---: |
| 8:30 及以前 | +¥1.50 |
| 8:30 后至 8:40 | +¥1.00 |
| 8:40 后至 9:30 | ¥0.00 |
| 9:30 以后 | −¥0.50 |

两个版本均支持：

- 首页和专注计时页均提供“查字”入口：输入汉字或词语，逐字查看田字格、总笔画和自动笔顺动画，可暂停、重播、用鼠标或手指跟写，并获得逐笔反馈和下一笔提示。查字时作业计时继续，返回后仍是原来的页面；不修改作业、顺序和完成记录。
- 查字内置 9,574 个汉字，全部离线；暂不提供拼音、释义或组词。网页版与安卓共用 `web/hanzi` 中的展示组件和字库，安卓仅此页面使用本地 WebView，主界面及作业逻辑继续使用原生 Java。字库按需读取，不在首页一次载入全部笔画数据；不申请网络权限，也不调用收费接口。
- 从顶部“听写”入口进入独立练习页，按课程选择四年级上册语文词语表；内置 25 组、共 318 个词语，也可以给任意课程追加和移除自定义词语；页面会记住上次选择的课程，并支持通过“上一课 / 下一课”快速切换；
- Android 和网页版均支持为每个词逐一录制、重录、试听和删除语音，孩子或家长都可以录制；每次停止并成功保存后会自动试听刚才的录音。本课词语录齐后才能开始听写，练习时每个词连续播放两遍，两遍之间停顿 1 秒；四字词与下一个词之间停顿 3 秒，其他词语停顿 2 秒，并显示当前进度；
- 从首页“作业计划”进入统一计划页面，返回、调整顺序和确定固定在顶部，录入栏固定在底部，中间清单独立滚动；选择科目，用键盘或关键词输入作业，在加号左侧选择预计用时后添加，默认 15 分钟，连续添加保留所选时长；文字清单优先按 `1.`、`2.`、`3.` 等序号分项，每项都使用所选时长，正文句号不会拆分任务；
- 录入、完成日期与可选排序共用一张清单，默认按录入先后执行，用颜色区分科目；补录接在末尾，删除撤销后回到原位，不重置已有顺序；
- “习惯打卡”在作业清单上方以两列常驻展示运动打卡、中文阅读、数学思维和英文阅读，显示各项状态及完成数；仅运动项目按需展开，原有打卡状态与时间保留。作业完成但习惯未完成时提示剩余项目，全部完成后才庆祝；作业结算规则不变；
- 确认作业清单后进入“闯关模式”：突出当前一项，只预告后两项，其余作业和已完成作业默认收起；
- 在录入页面点击“调整顺序”，可在每项右侧调整预计用时，并依次点选作业；修改时长会立即保存，保留已选顺序，最终顺序预览中也可修改。卡片保持原位并显示编号，支持撤销、重选，返回后可恢复排序草稿；
- 不调整顺序可直接点击右上角的“确定”；调整完成后也使用同一个按钮，一次保存作业、日期和顺序，再选择第一项开始时间；
- 开始作业后，首页和专注计时页提供“调整未开始顺序”：按先后点选当天可做的未开始作业，再确定保存。正在做、已暂停、已完成及未来日期作业保留原位，当前计时、记录和计划日期不变；取消保留原顺序。任意日期的计划均支持，少于两项可调整作业时隐藏入口；
- 闯关顺序确定后，第一项开始时间默认当前时间，确认即可开始；可点击“5分钟后”或“10分钟后”填入时间，也可自行选择时间，再确认保存。到点会提醒，孩子也可提前一键开始；
- 闯关顺序确定后，可以直接点击尚未开始的作业卡片，统一修改作业内容和预计用时，不会打乱已经排好的顺序；
- 统一计划清单使用相同卡片样式：内容旁放小铅笔，右侧依次放日期选择、估时（如“15 分钟”）和小删除图标，同排垂直居中；点击铅笔可一起修改内容和预计用时，保存后生效，取消则保留原值。调整顺序时仍可直接修改估时，不改变日期和已选顺序；
- 首页显示已做/总数和动态计算的“预计还需 × 分钟”；当前作业内容、修改图标和预计用时垂直居中，右侧保留整高的开始按钮；
- 专注页与开始安排页在右上角同排显示已完成/总数、轻快进度条和预计还需时间；暂停或跳过的作业也扣除已做用时，预计还需最低为 0 分钟；
- 清单确认后，当天可从作业清单、专注计时、下一项开始安排或休息倒计时中的“补加作业”追加老师新布置的任务；选择科目、内容与预计用时后直接加入今天清单末尾，原有任务顺序、完成记录、计时和提醒保持。补加只加入当天。若当天已全部完成，补加后取消原完成结算，待新作业完成后重新结算；
- 单项开始或继续时弹出专注计时卡，显示首次开始时间和实时用时；专注卡不提供关闭入口，只能完成、休息，或“跳过，开始下一项”。跳过会暂停当前项并保留累计用时，按原计划直接开始当天另一项未完成作业，不产生休息记录、不算完成；没有其他可做项时禁用跳过。刷新或重新打开后恢复当天正在进行的专注卡；
- 分别记录每项作业的开始、休息、继续、完成和实际用时；
- 专注页采用深蓝等宽计时数字、简洁白底和清晰分隔，科目色区分作业，辅助信息采用中性灰；休息倒计时采用薄荷绿与奶油色、圆润按钮和暂停标记，省去重复标题。休息页作业卡片上方显示距估时剩余或超时的分秒，仅按累计专注用时计算，休息及延长休息不计入；
- 每项作业完成后，只要当天还有可做的任务，就按已排好的顺序弹出“我准备什么时候开始下一项？”；默认当前时间，也可用“5分钟后”“10分钟后”快捷填入或自选时间，确认后执行。倒计时到点提醒，重新打开后可恢复；当天全部完成后不再弹窗；
- 作业进行中点击“休息一下”，可以选择休息 5、10 或 15 分钟，也可指定吃饭后的返回时间；
- 休息倒计时会在刷新或重新打开后继续，只允许延长一次 3 分钟，并保存计划返回时间与实际返回时间；休息到点后如果下一项仍未开始，每隔 5 分钟再次提醒一次；“设置 → 休息结束提醒”可录制、试听或重录提示音，未录音时提示“作业时间到啦”，Android 端同时震动；
- 设置页的“休息结束提醒”和“数据备份”只保留入口，详细操作各自在独立下级页面；返回后仍在设置页，离开录音页会停止录音和试听；
- 根据最终完成时刻自动计算奖罚；
- 按日期查看、补记或修改流程；
- 在“成长足迹”查看本周按计划完成天数、预计用时和实际用时，逐步提高孩子估时的准确度；
- 查看累计金额、记录天数、奖励天数和累计扣款；
- 日期设置、备份恢复和删除记录集中在家长工具或记录管理模式，不占用孩子的主要任务页面；
- 将全部记录导出为本地 JSON 备份，也可以恢复备份；网页版和 Android 版使用相同格式，可手动迁移数据；
- 每次导入前自动保存最近一份本机快照，在“设置 → 数据备份”中可恢复到上次导入前；保存失败时不替换当前记录。恢复后计时保持暂停，旧的休息和开始提醒清除；
- 在本机保存数据，不登录、不联网。

## 每天怎么用

查字资源约 31 MB（原始文件），按 ZIP/DEFLATE 压缩约 12.6 MB，预计增加约 13 MB 安装包体积；这是资源测量，不是 APK 构建测量。实际 APK 增量随打包配置变化。来源、固定版本和校验值见 `web/hanzi/provenance.json`，许可见 `THIRD_PARTY_NOTICES.md` 和查字页底部。维护时可用 `python scripts/vendor-hanzi.py` 重新生成固定版本字库；`python scripts/measure-hanzi.py` 可重新测量。源码检查和浏览器回归不代表安卓构建或真机测试通过。

1. 17:30 左右集中核对钉钉和成长记录册，先确定当天全部作业。
2. 点击“作业计划”，选择科目、输入内容，在加号左侧选择预计用时（默认 15 分钟），点击加号或按回车加入清单。也可点击作业旁的铅笔，或在“调整顺序”列表中修改已有作业的预计用时。
3. 上方显示所选日期的清单。默认只有今天，可展开“安排天数”加入后面几天；标签显示每天任务数。在哪个标签下添加，就安排到哪一天。
4. 当前顺序合适就直接点右上角的“确定”；需要调整则在同页点“调整顺序”，逐项选择后仍点同一个确认按钮。确认后选择第一项开始时间，不需要分别确认清单和排序。
5. 开始时间默认当前时间，点“现在开始”立即开始，暂停的作业显示“现在继续”；选择未来时间后按钮显示“确定开始时间”。“5分钟后”“10分钟后”按点击时的时间计算，只填入时间，不自动开始。确认未来时间后显示倒计时，到点播放提示，孩子也可以提前开始。专注卡显示开始时间和实时用时，同一时间只能有一项正在进行。
6. 每项写完点击“完成”，如果当天还有任务，就弹出下一项的开始安排；同样默认当前时间，支持 5/10 分钟后快捷填入或指定时间。倒计时结束会播放两遍提示音，Android 同时震动；尚未开始时每隔 5 分钟再提醒一次，一键即可开始已选定的下一项。作业中临时需要离开时可以点击“休息一下”。
7. 点击完成后会显示 8 秒的“已完成 · 撤销”提示。误点可直接撤销，正在计时的作业会继续，保留已做用时；开始下一项后此快捷撤销收起。当天作业全部完成后显示预计与实际用时的小复盘；习惯打卡也完成后显示通关庆祝，并按现有规则自动结算，无需再点“全部完成”。撤销最后一项会同步取消完成状态和相关结算。旧记录没有计时数据时，复盘显示“未记录”。

如果最后一项作业完成时还没有确认成长记录册，App 会先保存真实完成时刻；稍后确认成长记录册时仍按这个时刻结算，不会把核对时间算成写完时间。

“成长足迹”收进首页顶部的低干扰入口；累计金额、奖励统计、本周计划复盘和历史记录全部放在独立页面中，孩子需要时再主动查看，返回后继续当天任务。

当天页面不展示成长能量卡，保留紧凑的顶部、核对状态、习惯打卡和当前作业动作；日期选择位于设置中，作业清单显示完成数量和预计还需时间。未核对时不重复显示空作业卡。首页“录入作业”入口进入全屏下级页面，返回时保留清单与尚未添加的输入；四项习惯打卡始终可见，仅运动项目按需展开，已有本地记录仍会保留。

## 统一作业计划

平日、周末、长假共用首页的“作业计划”，不再根据星期自动合并周五到周日，也不再提供独立的假期设置入口。

- 默认只安排今天。展开“安排天数”，选择“再安排几天”并填写包含开始当天的总天数（1–366 天）。以后可以继续延长，也可以缩短显示范围；其他日期已有的作业都会保留。
- 标签只显示“今天 / 明天 / 第三天…”和当天任务数。真实日期放在预计总用时旁，以小字显示。在哪一天添加，作业就归到哪一天；日期范围重叠时共用原来的每日清单，不重复创建。
- 加号左侧选择估时；支持关键词、带序号的多项录入、一次性作业及按所选日期重复。内容旁的小铅笔修改内容与估时；右侧提供改期、估时和删除。选择目标天数后立即改期。
- 每天独立确认和执行，只需在页面右上角确认一次当前范围。未开始的作业可以调顺序；正在做、暂停和完成的记录保持，补加作业接在当天末尾。
- “之前未完成”汇总过去的未完成作业，点击“移到今天”安排补做，保留同一个任务和累计用时。不会自动把周末或其他日期的作业塞进今天。
- 不再区分上课日、休息日或假期。每天清单全部完成后，统一按现有完成时间规则结算；是否核对钉钉、补全成长记录册不影响奖励。撤销完成或补加作业后重新结算，刷新不会重复奖励。

首次打开和导入旧备份时，旧周末清单按原计划日期迁入每日记录，已完成项按实际完成日期保留，正在计时和提醒中的任务保留对应日期。原周末数据留作结算历史；迁移任务保留 ID、用时、状态、原计划日期，重复迁移不会再生成一份。旧假期作业继续使用原来的每日记录和重复组；旧数据中的日期类型标记不再影响奖励。历史结算保留，不因升级自动补发；之后完成的每日计划统一结算。备份沿用原字段格式，网页与安卓互通。

网页版统一日期规则在 `web/study-plans.js`，安卓对应 `StudyPlans.java`；`holiday-plans.js` / `HolidayPlans.java` 保留旧格式工具，旧假期页面由统一计划入口复用。新流程回归使用 `web/tests/study-plans.test.cjs`、`study-plans-browser.test.cjs`、`check-bindings.test.cjs`，计时与执行中的顺序另见 `pending-order-browser.test.cjs`、`task-recovery-browser.test.cjs`、`rest-timer-browser.test.cjs`。统一奖励、旧日期标记、完成时间边界及撤销/补加回归见 `daily-rewards-browser.test.cjs`。旧固定周末、假期设置页面的测试仅适用于改版前流程。

## 下载 PDF 与打印计划

在“作业计划”清单上方点击“下载 / 打印”，选择“当前一天”或“整个计划范围”，再点击“下载 PDF”或“打印”。当前一天指正在查看的日期标签；整个范围指页面中设置的全部安排天数。还有未添加的文字或未确认的排序时，先点加号或确定当天顺序后再导出。

- 每个日期从新的一页开始，包含日期、科目、作业内容、原任务顺序、预计用时、完成状态和勾选框。每天显示作业数量、预计总用时和已完成数量；长清单自动续页，长内容自动换行，空白日期也保留。纸张默认为 A4，有页码和可手写的备注区域。
- 网页版直接下载 `.pdf` 文件，也可打开浏览器打印窗口选择打印机或“另存为 PDF”。中文在本机以高分辨率页面图像写入 PDF，换设备打印无需另装字体；PDF 中的文字不能直接选中复制。离线库固定为 pdf-lib 1.17.1，不请求网络。
- 安卓原生版使用系统文件选择器保存 `.pdf`，也可调用系统打印服务选择打印机或“另存为 PDF”。使用原生 PDF 绘制，遵循所选纸张、页边距和打印页码范围；不申请额外存储权限。不同平台的字体和换行可能略有差异，日期、任务内容、顺序和状态一致。
- 下载和打印读取当前计划的独立快照，不修改任务、计时、确认状态、打卡或奖励；JSON 数据备份仍在“设置 → 数据备份”中。

导出规则及浏览器回归见 `web/tests/plan-export.test.cjs` 和 `web/tests/plan-export-browser.test.cjs`，覆盖实际 PDF 下载、日期范围、自动分页、空白日期、打印页面、失败重试、窄屏显示和原数据保留。安卓只检查源码语法，不代表构建、真机保存或实体打印验证通过。

## 使用网页版

直接双击 `web/index.html`，用浏览器打开即可。网页没有服务器依赖，也不需要安装任何软件。

记录保存在打开网页的这个浏览器中。清理浏览器的网站数据前，可以从独立的“设置”页导出备份；更换浏览器、换电脑或迁移到 Android 端时再选择恢复备份。孩子录制的休息提示音只保存在当前浏览器，不包含在 JSON 备份中。

## 使用 Android 源代码

1. 安装 Android Studio。
2. 选择“打开项目”，打开本项目中的 `android` 文件夹。
3. 等待 Android Studio 下载所需的 Gradle 和 Android SDK 组件。
4. 连接安卓手机或启动模拟器，然后点击运行。

Android 版使用 Java 和 Android 系统原生控件编写，最低支持 Android 6.0（API 23）。作业录入使用键盘和关键词，麦克风权限仅用于词语听写录音和自定义休息提示音。数据保存在应用自身的本地存储中；卸载前可从独立的“设置”页导出记录备份。备份包含作业、计划、打卡和自定义词语，不包含听写录音与休息提示音录音。

两个版本的词语听写都不包含 Kokoro、预生成音频或其他文字转语音模型，也不使用系统合成朗读；听写必须使用逐词人工录音。Android 词语录音保存在应用私有目录，网页版词语录音保存在当前浏览器的 IndexedDB 中。休息提醒未录制自定义声音时，Android 会用系统中文语音读出“作业时间到啦”。所有录音都不会上传网络；卸载应用或清除对应浏览器站点数据时会一并删除。

> 网页版和 Android 版各自在本机保存数据，不会自动同步；需要换设备时可通过同格式的本地备份手动迁移。

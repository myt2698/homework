# 作业小账本

一个完全本地使用的家庭作业奖罚记录工具，包含离线网页版和原生 Android 版源代码。

## 奖罚规则

| 完成时间 | 金额 |
| --- | ---: |
| 8:30 及以前 | +¥1.50 |
| 8:30 后至 8:40 | +¥1.00 |
| 8:40 后至 9:30 | ¥0.00 |
| 9:30 以后 | −¥0.50 |

两个版本均支持：

- 设置统计开始日期；
- 通过语音转文字或键盘录入作业，可用语文、数学、英语、科学单选标签快速归类；文字清单优先按 `1.`、`2.`、`3.` 等序号分项，正文句号不会拆分任务；
- 确认作业清单后进入“闯关模式”：突出当前一项，只预告后两项，其余作业和已完成作业默认收起；
- 清单确认后由孩子拖动卡片或使用上下箭头安排闯关顺序，确定后再按这个顺序完成；第一项开始后顺序自动锁定；
- 用进度条、“还剩几项”和分阶段鼓励语，让孩子随时看到自己正在接近终点；
- 单项开始或继续时弹出专注计时卡，显示首次开始时间和实时用时；
- 分别记录跳绳、仰卧起坐、50米跑、踢毽子和坐位体前屈等运动打卡；
- 每日记录阅读和家务打卡；
- 分别记录每项作业的开始、暂停、继续、完成和实际用时；
- 根据最终完成时刻自动计算奖罚；
- 按日期查看、补记或修改流程；
- 查看累计金额、记录天数、奖励天数和累计扣款；
- 删除历史记录；
- 在本机保存数据，不登录、不联网。

## 每天怎么用

1. 17:30 左右集中核对钉钉和成长记录册，先确定当天全部作业。
2. 点击“开始报作业”，按“科目＋内容”连续说完，也可以直接输入文字。
3. 核对自动生成的清单，确认没有遗漏后点击“确认作业清单”。
4. 孩子拖动卡片或使用上下箭头安排自己的闯关顺序，点击“确定顺序，开始闯关”。
5. App 会把排在第一项的作业显示为“当前关卡”，孩子点击“开始”；弹出的专注卡会显示开始时间和实时用时，同一时间只能有一项正在进行。
6. 每项写完点击“完成”，它会自动收进“已闯过”，下一项成为当前关卡；临时离开或吃饭可点击“暂停”，回来后点击“继续”。
7. 最后一项作业完成后显示通关庆祝，并自动记录整体完成时刻和结算，无需再点“全部完成”。
8. 运动完成后，在“运动打卡”中选择当天实际完成的项目，可以同时选择多项。

如果最后一项作业完成时还没有确认成长记录册，App 会先保存真实完成时刻；稍后确认成长记录册时仍按这个时刻结算，不会把核对时间算成写完时间。

## 周末任务包

周五、周六和周日会自动显示同一份“周末任务包”，不再按平日规则要求周五完成全部作业，也不会和平日奖励重复计算。

周五先核对钉钉和成长记录册，再一次性录入并确认完整清单。清单确认后，孩子先给每项作业选择“周五”“周六”或“周日”，再分别排列三天的闯关顺序，默认完成日是周六。安排保存后，周五可以立即完成当天的一部分；周六和周日会自动读取同一份清单和顺序，不再重新录入。周五未完成的项目会排在周六任务前，周六遗留项目会继续排在周日任务前。

为减少当前页面的干扰，三天任务分配和计划概览收在弹窗中，页面只保留一个“周五安排与闯关”入口；保存完成日并关闭弹窗后，再在作业清单中确定三天的闯关顺序。

周五只开放计划在周五完成的作业；周六先补周五遗留项，再完成周六计划；周日开放周日作业和前两天尚未完成的补做项。每项作业仍使用独立的开始、暂停、继续和完成计时。

周末奖罚分为两部分：

- 周五完成日期分配并确定三天的闯关顺序：+¥0.50；
- 每项都在自己计划的日期内完成：+¥1.00；
- 全部完成，但有作业晚于自己计划的日期：+¥0.50；
- 周日结束仍未完成：−¥0.50。

因此周末最高奖励仍为 ¥1.50。

## 使用网页版

直接双击 `web/index.html`，用浏览器打开即可。网页没有服务器依赖，也不需要安装任何软件。

记录保存在打开网页的这个浏览器中。清理浏览器的网站数据、更换浏览器或换电脑后，原记录不会自动迁移。

## 使用 Android 源代码

1. 安装 Android Studio。
2. 选择“打开项目”，打开本项目中的 `android` 文件夹。
3. 等待 Android Studio 下载所需的 Gradle 和 Android SDK 组件。
4. 连接安卓手机或启动模拟器，然后点击运行。

Android 版使用 Java 和 Android 系统原生控件编写，最低支持 Android 6.0（API 23），没有第三方运行依赖。语音录入调用手机自带的语音识别服务；如果手机没有可用服务，仍可直接输入文字。数据保存在应用自身的本地存储中；卸载应用会同时删除记录。

> 网页版和 Android 版各自在本机保存数据，目前不会自动同步。

# 作业小账本

一个完全本地使用的家庭作业奖罚记录工具，包含离线网页版和原生 Android 版源代码。

## 奖罚规则

| 完成时间 | 金额 |
| --- | ---: |
| 8:30 及以前 | +¥1.50 |
| 8:30 后至 8:40 | +¥1.00 |
| 8:40 后至 9:30 | ¥0.00 |
| 9:30 以后 | −¥0.50 |

两个版本均支持：

- 从顶部“听写”入口进入独立练习页，按课程选择四年级上册语文词语表；内置 25 组、共 318 个词语，也可以给任意课程追加和移除自定义词语；页面会记住上次选择的课程，并支持通过“上一课 / 下一课”快速切换；
- Android 和网页版均支持为每个词逐一录制、重录、试听和删除语音，孩子或家长都可以录制；每次停止并成功保存后会自动试听刚才的录音。本课词语录齐后才能开始听写，练习时每个词连续播放两遍，两遍之间停顿 1 秒；四字词与下一个词之间停顿 3 秒，其他词语停顿 2 秒，并显示当前进度；
- 从首页“录入作业”入口打开弹窗，在同一个页面完成离线中文语音或键盘录入、待确认清单核对、删除和确认；语音识别完全在手机本机运行，不需要系统语音服务和网络；可用语文、数学、英语、科学单选标签快速归类，文字清单优先按 `1.`、`2.`、`3.` 等序号分项，正文句号不会拆分任务；
- 弹窗内的待确认清单固定按语文、数学、英语、科学排列，同一科目内按录入先后排列；确认后首页才显示由孩子安排顺序和执行的闯关清单；
- 每日任务默认收进“今日习惯”入口并显示完成数，展开后可分别打卡；运动可选择跳绳、踢毽子、坐位体前屈、50米和仰卧起坐，中文阅读、数学思维、英文阅读分别记录完成状态与时间；
- 确认作业清单后进入“闯关模式”：突出当前一项，只预告后两项，其余作业和已完成作业默认收起；
- 清单确认后由孩子拖动卡片或使用上下箭头安排闯关顺序，并在队列中设置最多两个休息点；确定后再按这个顺序完成，第一项开始后顺序自动锁定；
- 闯关顺序确定后，可以直接点击尚未开始的作业卡片，统一修改作业内容、预计用时和步骤，不会打乱已经排好的顺序；
- 安排顺序时由孩子为每项作业选择预计用时（5、10、15、20 或 30 分钟）；平日还可以在某项后设置“吃饭”分界，清楚区分饭前和饭后计划；
- 耗时较长的作业可以拆成多个小步骤，专注卡会提示当前步骤，完成一步后继续下一步，最后一步完成才算整项完成；
- 用紧凑进度条显示完成比例、饭前或饭后阶段，以及根据未完成项目动态计算的预计剩余时间；
- 单项开始或继续时弹出专注计时卡，显示首次开始时间和实时用时；
- 分别记录每项作业的开始、休息、继续、完成和实际用时；
- 普通作业完成后直接突出下一项；只有完成预先设置的休息点，才自动打开休息安排。孩子可以直接选择休息 5、10 或 15 分钟，也可指定吃饭后的返回时间；
- 休息倒计时会在刷新或重新打开后继续，只允许延长一次 3 分钟，并保存计划返回时间与实际返回时间；顶部“设置”可录制、试听或重录休息结束提示音，未录音时提示“作业时间到啦”，Android 端同时震动；
- 根据最终完成时刻自动计算奖罚；
- 按日期查看、补记或修改流程；
- 在“成长足迹”查看本周按计划完成天数、预计用时和实际用时，逐步提高孩子估时的准确度；
- 查看累计金额、记录天数、奖励天数和累计扣款；
- 日期设置、备份恢复和删除记录集中在家长工具或记录管理模式，不占用孩子的主要任务页面；
- 将全部记录导出为本地 JSON 备份，也可以恢复备份；网页版和 Android 版使用相同格式，可手动迁移数据；
- 在本机保存数据，不登录、不联网。

## 每天怎么用

1. 17:30 左右集中核对钉钉和成长记录册，先确定当天全部作业。
2. 点击“录入作业”打开弹窗，再点击“开始报作业”，按“科目＋内容”连续说完，也可以直接输入文字；生成一科后可留在弹窗中继续录下一科。
3. 直接在同一弹窗下方核对自动生成的清单，可删除错误项目；确认没有遗漏后点击“确认作业清单”。
4. 孩子拖动卡片或使用上下箭头安排自己的闯关顺序，同时估计每项需要几分钟，并设置最多两个休息点；长作业可以拆成几步，平日可选择“饭前到这里”，再点击“确定顺序，开始闯关”。
5. App 会把排在第一项的作业显示为当前任务，并持续显示预计还需要多少分钟；孩子点击“开始”后，专注卡会显示开始时间、当前步骤和实时用时，同一时间只能有一项正在进行。
6. 每项或每一步写完点击“完成”，普通作业直接突出下一项；到达预设休息点时，孩子选择上厕所、短休息、较长休息或吃饭返回时间，必要时可更换一次下一项。倒计时结束会播放两遍提示音，Android 同时震动，回来后一键开始已经确定的下一项。临时需要离开时也可以点击“休息一下”。
7. 最后一项作业完成后显示通关庆祝，并自动记录整体完成时刻和结算，无需再点“全部完成”。

如果最后一项作业完成时还没有确认成长记录册，App 会先保存真实完成时刻；稍后确认成长记录册时仍按这个时刻结算，不会把核对时间算成写完时间。

“成长足迹”收进首页顶部的低干扰入口；累计金额、奖励统计、本周计划复盘和历史记录全部放在独立页面中，孩子需要时再主动查看，返回后继续当天任务。

当天页面不再展示成长能量卡，优先呈现日期和当前作业动作；手机端使用紧凑的顶部、日期栏和核对状态，闯关时只显示一组完成数量与进度条，减少卡片套层，让当前作业尽量直接进入首屏。未核对时不重复显示空作业卡。每日录入工具收进弹窗，首页保留简洁的“录入作业”入口；运动、中文阅读、数学思维、英文阅读收进可展开的“今日习惯”，已有本地记录仍会保留。

## 周末任务包

周五、周六和周日会自动显示同一份“周末任务包”，不再按平日规则要求周五完成全部作业，也不会和平日奖励重复计算。

周五先核对钉钉和成长记录册，再一次性录入并确认完整清单。清单确认后，孩子先给每项作业选择“周五”“周六”或“周日”，再分别排列三天的闯关顺序，默认完成日是周六。安排保存后，周五可以立即完成当天的一部分；周六和周日会自动读取同一份清单和顺序，不再重新录入。周五未完成的项目会排在周六任务前，周六遗留项目会继续排在周日任务前。

为减少当前页面的干扰，三天任务分配和计划概览收在弹窗中，页面只保留一个“周五安排与闯关”入口；保存完成日并关闭弹窗后，再在作业清单中确定三天的闯关顺序。

周五只开放计划在周五完成的作业；周六先补周五遗留项，再完成周六计划；周日开放周日作业和前两天尚未完成的补做项。每项作业仍使用独立的开始、休息、继续和完成计时。

周末奖罚分为两部分：

- 周五完成日期分配并确定三天的闯关顺序：+¥0.50；
- 每项都在自己计划的日期内完成：+¥1.00；
- 全部完成，但有作业晚于自己计划的日期：+¥0.50；
- 周日结束仍未完成：−¥0.50。

因此周末最高奖励仍为 ¥1.50。

## 使用网页版

直接双击 `web/index.html`，用浏览器打开即可。网页没有服务器依赖，也不需要安装任何软件。

记录保存在打开网页的这个浏览器中。清理浏览器的网站数据前，可以从独立的“设置”页导出备份；更换浏览器、换电脑或迁移到 Android 端时再选择恢复备份。孩子录制的休息提示音只保存在当前浏览器，不包含在 JSON 备份中。

## 使用 Android 源代码

1. 安装 Android Studio。
2. 选择“打开项目”，打开本项目中的 `android` 文件夹。
3. 等待 Android Studio 下载所需的 Gradle 和 Android SDK 组件。
4. 连接安卓手机或启动模拟器，然后点击运行。

Android 版使用 Java 和 Android 系统原生控件编写，最低支持 Android 6.0（API 23）。作业语音录入使用 APK 内置的 sherpa-onnx 中文流式识别模型，首次使用时只需授予麦克风权限，不需要联网或安装手机系统语音服务；仍可随时直接输入文字。当前 APK 支持 `arm64-v8a` 和 `armeabi-v7a` 真机架构。数据保存在应用自身的本地存储中；卸载前可从独立的“设置”页导出记录备份。备份包含作业、计划、打卡和自定义词语，不包含听写录音与休息提示音录音。

两个版本的词语听写都不包含 Kokoro、预生成音频或其他文字转语音模型，也不使用系统合成朗读；听写必须使用逐词人工录音。Android 词语录音保存在应用私有目录，网页版词语录音保存在当前浏览器的 IndexedDB 中。休息提醒未录制自定义声音时，Android 会用系统中文语音读出“作业时间到啦”。所有录音都不会上传网络；卸载应用或清除对应浏览器站点数据时会一并删除。

> 网页版和 Android 版各自在本机保存数据，不会自动同步；需要换设备时可通过同格式的本地备份手动迁移。
